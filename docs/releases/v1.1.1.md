# numpyrge256 v1.1.1 - Documentation Refresh and Ecosystem Alignment

[![GitHub Release](https://img.shields.io/github/v/release/RRG314/numpyrge256)](https://github.com/RRG314/numpyrge256/releases)
[![PyPI version](https://img.shields.io/pypi/v/numpyrge256)](https://pypi.org/project/numpyrge256/)

## Overview

This release updates the repository surface around the existing NumPy package. The implementation stays the same; the main changes are better documentation, clearer ecosystem positioning, and cleaner release tracking.

## What Changed

- clarified when to use the NumPy package instead of the broader `rge256` suite or the browser demos
- added explicit links to the research program and companion repos
- added a changelog and release-note trail
- kept the package API unchanged

## Intended Use

Use `numpyrge256` when you want deterministic array generation in standard scientific Python workflows without bringing in PyTorch.
